# Famulus releases

Public downloads for [Famulus](https://famuluslearning.com), the local-first study desk for macOS and Windows.
The source code is private; this repository only carries the release builds.

Beta builds are not yet notarized. On macOS, open the app once, then go to System Settings → Privacy & Security → Open Anyway.

Questions, bug reports or a request for an Intel build: open an issue.
